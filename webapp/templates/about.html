CalTopo Viewshed

CalTopo already has a built-in viewshed layer — this project isn't trying to replace it. I wanted to understand how one actually works, so I rebuilt it myself, starting from a from-scratch visibility algorithm validated against CalTopo's own tool. It's grown since then into this small web app: upload a hiking route, and it shows you exactly what terrain — and which named peaks and lakes — you can see from every point along it.

A viewshed is the set of terrain visible from a given point, accounting for the ground blocking your view of anything behind it. The core of this project is a rotational horizon sweep: rays cast outward from the observer in every direction, tracking the steepest angle seen so far along each ray so a point is only visible if nothing closer in already blocks it — corrected for Earth curvature and atmospheric refraction, and validated directly against CalTopo's own built-in viewshed for the same point.
